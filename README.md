# Cedi Ledger

A simple daily sales and expense tracker for small businesses in Ghana. Add sales and expenses in cedis, see your profit for the day, and export everything to CSV.

Built with plain HTML, CSS and JavaScript. No frameworks, no backend. Data is saved in your browser (localStorage), so it stays on your device.

## Features

- Add sales and expenses with an amount in GH₵
- Live totals for sales, expenses and profit
- Delete single entries or clear the day
- Download all entries as a CSV file
- Works on phones and supports dark mode

## Run it

Open `index.html` in your browser. That's all.

## Host it on GitHub Pages

1. Create a new repo, e.g. `cedi-ledger`, and push these files.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site goes live at `https://iamchairmano2.github.io/cedi-ledger/`.
